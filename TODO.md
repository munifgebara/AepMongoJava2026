# Evoluções futuras

Estas possibilidades estão deliberadamente fora do escopo inicial:

- paginação;
- ordenação;
- busca por nome;
- filtros;
- validação de duplicidade;
- `PATCH`;
- OpenAPI / Swagger;
- autenticação;
- autorização;
- métricas;
- observabilidade;
- integração contínua (CI);
- GitHub Actions;
- controle de versões da API;
- auditoria.

As funcionalidades devem ser priorizadas conforme os objetivos pedagógicos da disciplina, sem implementação antecipada.
